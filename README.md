# 클래시 로얄 밸런스 연구소 (Clash Royale Balance Lab)

한국어 카드 효율표와 덱 연구소를 한 화면에서 탐색할 수 있는 **PC·모바일 반응형 정적 웹사이트**입니다.

## 주요 기능

- 카드·형태 190개 한국어 명칭 및 공식 카드 이미지 **외부 URL** 연결
- 랭크전/그랜드 도전 카드별 통계와 효율표, 카드 비교
- 카드 1~3장 선택 시 **선택한 카드 모두가 포함된 대표 덱** 필터링
- 대표 덱 구성(8장)·평균 엘릭서·운용 가이드·상성 후보 설명
- 확인 가능한 일부 덱 통계 또는 사용자 입력 전적 표시
- RoyaleAPI 외부 덱 검색 연결
- 데스크톱과 모바일 화면 대응

## 실행 및 배포

이 저장소의 `index.html` 파일이 웹사이트 시작점입니다.

GitHub Pages에서 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** 순서로 설정하면 사이트를 배포할 수 있습니다.

설정 후 예상 주소: https://jarh0907-ui.github.io/clash-royale-balance-lab/

## 데이터 관련 주의

- **실시간 자동 갱신은 없습니다.** 기존 내장 통계는 수집 당시의 스냅샷입니다.
- 내장된 대표 덱 40개는 전체 실시간 덱 데이터베이스가 아닙니다. 덱별 픽률/승률을 확인할 수 없는 항목은 미집계 상태로 표시합니다.
- 카운터 후보는 실제 상대전적을 기반으로 확정한 순위가 아닌 **전략적 추정**입니다.
- 이미지 파일을 저장소에 포함하지 않습니다. 외부 이미지 서버가 응답하지 않으면 일부 카드 이미지가 나타나지 않을 수 있습니다.
- 팬 제작 분석 도구이며 Supercell 공식 사이트가 아닙니다.

## v1.6 카드 도감 업데이트 (2026-11-15)

- **전체 카드 → 큰 카드** 화면: 공식 이미지의 세로 비율을 보존한 카드형 목록과 이미지 아래 한국어 이름. PC/모바일 반응형 3열(좁은 화면), 표형 전환도 지원.
- 카드 그림을 누르면 **게임풍 카드 상세창**: 확대 이미지, 엘릭서, 형태/희귀도, 설명, 체력·피해량·DPS·공격 속도·사거리·대상·배치 수 등 확인된 속성을 카드 특성에 따라 표시합니다.
- 스탯은 `data/card-stats-level11.json` 파일로 관리합니다. 커뮤니티 기반 레벨 11 **2026-08-26 스냅샷 180항목**이며 2026년 11월 패치 후 수치와 다를 수 있습니다. 자료가 없는 형태는 임의 수치를 만들지 않습니다. 최신 수치 확인은 [crtool 한국어 카드 데이터베이스](https://crtool.app/ko/units/)를 참고하세요.
- 공식 카드 그림은 계속 외부 서버에서 불러옵니다. 이미지 원본을 저장소에 포함하지 않습니다.
- 신규 파일: `assets/card-ui-v16.css`, `assets/card-ui-v16.js`, `data/card-stats-level11.json`.


## v1.7 카드 정보창 개선 (2026-11-15)

- 카드 클릭 시 오른쪽 서랍 대신 **선택 카드 위치를 기준으로 화면 안에 배치되는 중앙 오버레이 팝업**이 열립니다. 모바일에서는 안전한 화면 중앙에 표시됩니다.
- 클래시 로얄 카드 정보창을 참고한 네이비 패널, 카드 이미지/이름/레벨 배치, 붉은 닫기 버튼 및 밝은 능력치 표 디자인입니다. 원본 게임 UI를 그대로 복제하지는 않았습니다.
- **카드 능력치 / 실전·밸런스** 탭으로 내용을 나눴습니다. 외부 이미지 URL 및 기존 한국어 스탯/덱 연구소/수동 점수 기록은 유지합니다.
- 새 파일: `assets/card-popup-v17.css`, `assets/card-popup-v17.js`. 배포 확인 시 브라우저에서 강력 새로고침을 권장합니다.

## v1.8 게임풍 카드 정보 팝업

- HTML에 직접 들어 있던 **오른쪽 서랍 마크업을 제거**하고 선택 카드 위로 겹쳐 뜨는 **화면 중앙 오버레이**로 교체했습니다. 이 변경은 별도 팝업 CSS 파일 로딩에 의존하지 않습니다.
- 클래시 로얄 카드 정보창을 참고하여 파란색 프레임, 왼쪽 카드 그림, 오른쪽 이름·레벨·희귀도/유형, 밝은 두 열 능력치 표, 빨간 닫기 버튼과 하단 페이지 표시를 구현했습니다.
- 두 탭: **정보**(레벨 11 스탯) 및 **실전 통계·밸런스**(기존 분석과 수동 평가). 모바일/PC 모두 화면 안에 표시됩니다.
- 이미지 파일은 여전히 외부 URL로 로딩되며, 레벨 11 스탯 자료의 업데이트 한계는 그대로 적용됩니다.
- 적용 확인용 URL: `https://jarh0907-ui.github.io/clash-royale-balance-lab/?v=18` (HTML 캐시 갱신)

## v1.9 카드 정보창 고도화 (2026-11-15)
