# 클래시 로얄 밸런스 연구소 (Clash Royale Balance Lab)

한국어 카드 효율표와 덱 연구소를 한 화면에서 탐색할 수 있는 **PC·모바일 반응형 정적 웹사이트**입니다.

## 주요 기능

- 카드·형태 190개 한국어 명칭 및 공식 카드 이미지 **외부 URL** 연결
- 랭크전/그랜드 도전 카드별 통계와 효율표, 카드 비교
- 카드 1~3장 선택 시 **선택한 카드 모두가 포함된 대표 덱** 필터링
- 대표 덱 구성(8장)·평균 엘릭서·운용 가이드·상성 후보 설명
- 확인 가능한 일부 덱 통계 또는 사용자 입력 전적 표시
- RoyaleAPI 외부 덱 검색 연결
- 데스크톱과 모바일 화면 대응

## 실행 및 배포

이 저장소의 `index.html` 파일이 웹사이트 시작점입니다.

GitHub Pages에서 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** 순서로 설정하면 사이트를 배포할 수 있습니다.

설정 후 예상 주소: https://jarh0907-ui.github.io/clash-royale-balance-lab/

## 데이터 관련 주의

- **실시간 자동 갱신은 없습니다.** 기존 내장 통계는 수집 당시의 스냅샷입니다.
- 내장된 대표 덱 40개는 전체 실시간 덱 데이터베이스가 아닙니다. 덱별 픽률/승률을 확인할 수 없는 항목은 미집계 상태로 표시합니다.
- 카운터 후보는 실제 상대전적을 기반으로 확정한 순위가 아닌 **전략적 추정**입니다.
- 이미지 파일을 저장소에 포함하지 않습니다. 외부 이미지 서버가 응답하지 않으면 일부 카드 이미지가 나타나지 않을 수 있습니다.
- 팬 제작 분석 도구이며 Supercell 공식 사이트가 아닙니다.
